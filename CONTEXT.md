# dallinjanderson.com

Dallin Anderson's personal site: an internet workshop and long-term archive of the things he has made, learned, and explored. It is not a résumé or a business site.

## Language

**Project**:
Something Dallin built that lives somewhere other than this site, described here rather than run here. Commercial success is irrelevant: dormant and abandoned work still counts.
_Avoid_: Portfolio piece, work, case study

**Experiment**:
A small, self-contained interactive thing whose code lives in this repository and which runs on this site. Games, tools, visualisations, puzzles, toys.
_Avoid_: Demo, app, sandbox, playground item

**Playground**:
The collection of all Experiments, and the gallery that indexes them.
_Avoid_: Labs, sandbox, toys

**Post**:
A piece of writing: a technical note, something learned while building, an essay, or a fiction-adjacent piece. All writing is one kind of thing, distinguished only by its content.
_Avoid_: Article, blog post, entry, note, essay

**Notes** (on an Experiment):
Optional prose accompanying an Experiment, explaining what it is and what Dallin learned from it. Distinct from a Post: Notes cannot exist independently of their Experiment.
_Avoid_: Description, write-up, readme

**Now**:
The short, frequently-changing statement of what Dallin is currently building, writing, and exploring.
_Avoid_: Status, currently, bio

## Distinctions worth holding onto

**Project vs Experiment** is decided by _where the thing runs_, never by how significant it is. An Experiment runs here; a Project runs elsewhere. A small abandoned side project that lives in its own repository is a Project, not an Experiment. A Project may embed an Experiment when one exists, but each has exactly one canonical home.
